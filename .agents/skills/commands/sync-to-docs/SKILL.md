# Command: /sync-to-docs

1. Baca Google Docs target dari `thesis.config.json`.
2. Format draf dari folder `drafts/` menjadi format terstruktur.
3. Konfirmasi ringkasan pembaruan ke pengguna.
4. Tulis konten ke Google Docs.
