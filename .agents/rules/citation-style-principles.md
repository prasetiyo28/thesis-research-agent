# Citation & Referencing Principles

- Default Style: APA 7th Edition (dapat disesuaikan via `thesis.config.json`).
- Format In-text: (NamaBelakang, Tahun) atau "Menurut NamaBelakang (Tahun)..."
- Multiple Authors: Gunakan "et al." untuk referensi dengan 3 penulis atau lebih.
- Entri daftar pustaka wajib memuat tautan DOI aktif jika tersedia.
