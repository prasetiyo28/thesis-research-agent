# Google Docs Formatting Principles

1. Gunakan Heading 1 untuk Judul Bab, Heading 2 untuk Sub-bab, dan Heading 3 untuk Bagian Spesifik.
2. Judul Tabel diletakkan di **atas** tabel (Tabel X.X).
3. Keterangan Gambar (caption) diletakkan di **bawah** gambar (Gambar X.X).
4. Kutipan langsung panjang (> 40 kata) diformat sebagai indented blockquote.
