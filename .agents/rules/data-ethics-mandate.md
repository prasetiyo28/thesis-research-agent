# Data Ethics & Compliance Mandate

1. **Consent & Privacy**: Dilarang menggunakan atau menyajikan data identitas pribadi (PII) tanpa proses anonymization.
2. **Open Access Licensing**: Pastikan dataset yang digunakan mematuhi lisensi pemakaian (MIT, CC-BY, Open Data Commons).
3. **Web Extraction Protocols**: Pengerukan data web hanya diizinkan dari domain publik resmi dan mematuhi file robots.txt serta terms of service sumber data.
