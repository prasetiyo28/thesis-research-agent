# Thesis & Academic Research Agent Suite

Rangkaian aturan, keahlian, dan persona sub-agen berbasis arsitektur AGV untuk penelitian dan penyusunan tesis, terintegrasi dengan Google Docs.

## Fitur Utama
- **Rules Mandat**: Menjamin bebas halusinasi sitasi dan etika data.
- **Skills On-Demand**: Sintesis literatur, audit data statistik, dan penulisan ilmiah.
- **Slash Commands**:
  - \`/critique <bab>\`: Uji kritis draf bab ala dosen penguji.
  - \`/sync-to-docs <bab>\`: Tulis/sinkronkan bab ke Google Docs.
  - \`/find-papers\`: Pencarian literatur terakreditasi.

## Menghubungkan ke Google Docs
Masukkan URL atau ID dokumen Google Docs Anda pada file \`thesis.config.json\`.
